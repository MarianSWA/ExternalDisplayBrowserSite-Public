XeOS 브라우저: 탭, 광고 차단, 다운로드, 읽기 모드 그리고 그 밖의 모든 것

브라우저는 XeOS에서 가장 많은 시간을 보내게 될 곳이며, 휴대폰용 브라우저가 아니라 데스크톱 브라우저처럼 동작합니다. 드래그할 수 있는 탭, 북마크 바, 전송 속도를 알려주는 다운로드 목록. 비밀번호, 광고 차단, 리더 모드, 페이지 내 찾기까지. 이 페이지는 이 모든 것을 정리한 참고 자료이니, 제목만 훑어보고 필요한 곳에서 멈추세요.

탭

  • Cmd T로 탭을 열고, Cmd W로 탭을 닫고, Cmd Shift T로 방금 닫은 탭을 다시 엽니다.
  • 탭을 드래그해 순서를 바꾸세요. 탭을 가운데 클릭하면 닫힙니다.
  • 탭을 오른쪽 클릭하면 새로고침, 복제, 플로팅 창으로 열기, 닫기를 할 수 있습니다.
  • 탭은 지연 로딩됩니다. 탭 스무 개짜리 세션을 다시 열어도 스무 페이지가 한꺼번에 불러와지지 않습니다.

주소 표시줄

URL이나 검색어를 입력하세요. 검색 엔진은 직접 선택할 수 있습니다. ⋯ › Change search engine에서 Google, DuckDuckGo, Bing, Yahoo, Ecosia, Brave, Startpage 중에서 고를 수 있습니다. ⋯ › Change homepage는 홈 버튼이 이동할 위치를 설정합니다. 비워두면 홈 버튼은 검색 엔진으로 이동합니다.

광고 차단

차단기는 EasyList와 uBlock 필터 목록으로 만들어져 브라우저 엔진에 컴파일되어 있으므로 설치할 확장 프로그램이 따로 없습니다. 이미 작동 중입니다.

Block Ads는 전역 스위치로, YouTube 동영상 광고도 차단합니다. 변경하면 페이지가 다시 로드됩니다. Block Ads on This Site는 광고가 로드되지 않으면 오류가 나는 간혹 있는 사이트를 위한 옵션입니다.

북마크

  • 툴바의 별표는 현재 페이지를 북마크합니다.
  • Cmd Shift B로 북마크 바를 보이거나 숨깁니다.
  • 바에서 북마크를 드래그해 순서를 바꾸거나, 폴더 위로 드래그해 정리하세요.
  • 북마크를 오른쪽 클릭하면 새 탭에서 열기, 편집, 삭제를 할 수 있습니다.
  • Manage bookmarks는 설정에서 폴더와 드래그 앤 드롭이 가능한 전체 관리자를 엽니다.

다른 브라우저에서 북마크를 가져오는 방법은 가져오기 가이드에서 다룹니다.

비밀번호

⋯ › Passwords는 저장된 로그인 정보 패널을 열어 검색, 표시, 복사, 삭제를 할 수 있게 해줍니다.

저장된 로그인 정보는 로그인 양식에서 자동 채우기로 제안됩니다. iOS 키체인에 보관된 키로 기기에서 암호화되며, 어디에도 업로드되지 않습니다.

다운로드

툴바의 다운로드 버튼을 누르면 진행 상황, 전송 속도, 남은 시간, 취소 버튼이 있는 다운로드 목록이 열립니다.

  • 완료된 파일은 자동으로 열리지 않습니다. 언제 열지는 사용자가 결정합니다.
  • 압축 파일은 열기 대신 압축 풀기 동작이 제공됩니다.
  • 다운로드를 취소하면 잔여 파일을 남기지 않고 부분 파일을 삭제합니다.
  • Open Folder는 파일 앱의 다운로드 폴더로 바로 이동합니다.

읽기 모드

Cmd Shift R, 또는 페이지가 지원할 때 주소 표시줄에 나타나는 리더 버튼을 누르면 페이지를 텍스트와 이미지만 남기고 단순화합니다. 멀리 떨어진 큰 화면에서는 이 차이가 기사를 편안히 읽는 것과 눈을 찡그리며 보는 것의 차이가 됩니다.

읽기 목록

⋯ › Add to Reading List는 나중에 볼 페이지를 저장합니다. Open Reading List는 검색창과 함께 저장한 항목을 보여줍니다. 항목은 새 탭에서 열립니다.

페이지 내 찾기

Cmd Shift F로 찾기 바를 엽니다. Enter는 다음 일치 항목으로, Shift Enter는 이전 항목으로 이동합니다.

확대/축소

Cmd +, Cmd −, Cmd 0. 확대/축소 수준은 사이트별로 기억되며 페이지 이동 후에도 유지되므로, 글자가 작은 사이트는 방문할 때마다 확대된 상태로 남아 있습니다.

데스크톱 버전과 모바일 버전

기본적으로 사이트의 데스크톱 버전을 볼 수 있습니다. 이것이 이 앱 전체의 핵심 포인트입니다. 하지만 ⋯ › Load mobile version of site는 특정 사이트만 휴대폰 레이아웃으로 전환하며, 이는 이상하게 작동하는 페이지를 가장 빠르게 해결하는 방법이 될 때가 있습니다.

페이지 저장하기

페이지를 오른쪽 클릭하고 다른 이름으로 저장…을 선택하면 HTML과 자산 폴더까지 파일 앱에 전체 사본으로 보관됩니다. 저장한 페이지는 브라우저에서 다시 열립니다.

사이트 데이터 지우기

⋯ › Clear Site Data는 쿠키, 캐시, 로컬 및 세션 저장소 등 특정 사이트가 기기에 저장한 모든 것을 지우고 처음부터 다시 불러옵니다. 사이트가 로그인 루프에 걸렸을 때 해결책입니다.

로그인 상태 유지하기

사이트 세션은 설계상 재시작 후에도 유지됩니다. 한 번 로그인하면 케이블을 뽑았다 다시 연결해도 모든 사이트에서 로그인 상태가 유지됩니다.
