iPhone이나 iPad로 TV나 모니터에서 YouTube를 전체 화면으로 보는 방법

TV, iPhone, 케이블이 있고, 화면 가운데 휴대폰 모양 사각형 안에 갇히는 대신 영상이 화면을 가득 채우길 원한다고 해봅시다. XeOS로는 5분이면 끝납니다. 로그인하고, 전체 화면으로 전환하고, 내장 광고 차단기가 일하도록 두면 됩니다.

디스플레이가 아직 연결되지 않았다면 먼저 설정 가이드를 진행하세요.

미러링으로는 부족한 이유

iOS 화면 미러링은 휴대폰 화면을 그대로 TV로 보냅니다. 휴대폰은 대략 19.5:9이고 TV는 16:9이므로, TV는 그 차이를 양옆의 검은 여백으로 채웁니다. YouTube 영상은 그렇게 여백이 채워진 화면 안에서 다시 한번 레터박스 처리됩니다. YouTube의 전체 화면 버튼을 눌러도 소용없는데, 이 제약은 YouTube보다 한 단계 위에 있기 때문입니다.

XeOS는 미러링하지 않습니다. 디스플레이 자체의 해상도로 데스크톱을 렌더링하므로 전체 화면 영상이 패널을 가득 채웁니다.

1단계: YouTube에 로그인하기

독에서 브라우저를 열고 youtube.com으로 이동하세요. 컴퓨터에서처럼 Google 계정으로 로그인하세요. 구독 목록, 시청 기록, 나중에 볼 동영상까지 포함된 데스크톱 사이트를 그대로 사용할 수 있습니다.

로그인을 덜 번거롭게 해주는 두 가지가 있습니다. 첫째, Safari, Chrome, Firefox, Edge에서 비밀번호를 가져오면 로그인이 탭 한 번으로 끝납니다. 둘째, 세션이 유지됩니다. XeOS는 재시작 후에도 사이트 쿠키와 저장소를 유지하므로 연결할 때마다가 아니라 한 번만 로그인하면 됩니다.

Google 로그인 페이지에서 클릭이 먹히지 않는 요소가 있다면, 대개 동의 상자나 내장 프레임 때문이며 이는 기기 레이아웃 모드에서 설명한 iOS 엔진의 제약입니다. 회색 버튼을 탭해 휴대폰 화면에서 그 한 단계를 처리하고 바로 돌아오세요.

2단계: 광고 차단 켜기

XeOS에는 EasyList와 uBlock 필터 목록으로 만들어져 브라우저 엔진 자체에 컴파일된 광고 차단기가 기본 탑재되어 있습니다. 기본으로 켜져 있어 보통 따로 할 일은 없지만, 필요하다면 이 스위치를 확인하세요.

툴바 오른쪽의 ⋯ 버튼을 클릭하세요.

Block Ads는 전역 스위치로, YouTube 동영상 광고를 포함해 모든 사이트의 광고와 추적기를 차단합니다. 변경하면 페이지가 다시 로드됩니다. Block Ads on This Site는 광고 없이는 오류가 나는 사이트를 위해 특정 사이트만 차단을 끕니다.

YouTube에는 추가 편의 기능도 있습니다. 건너뛸 수 있는 광고가 나타나면 건너뛰기 버튼이 자동으로 눌리므로, 무인 화면이 저녁 내내 광고 카운트다운에 멈춰 있는 일이 없습니다.

3단계: 전체 화면으로 전환하기

여기에는 서로 다른 역할을 하는 두 가지 전체 화면이 있습니다.

YouTube 자체의 전체 화면 버튼

플레이어 오른쪽 아래 모서리의 버튼은 컴퓨터에서처럼 동작해 영상을 브라우저의 페이지 영역 전체로 확장합니다. 많은 모바일 브라우저가 실패하는, 사이트가 영상을 내장 프레임 안에서 재생하는 경우에도 XeOS는 이를 올바르게 처리합니다.

창의 초록색 버튼

가장 깔끔한 결과를 위해서는 창도 전체 화면으로 만드세요. 왼쪽 위 모서리의 초록색 버튼을 클릭하세요.

브라우저 크롬, 독, 상태 오버레이가 모두 사라지고 YouTube 플레이어가 브라우저를 채우며, 브라우저가 디스플레이를 채우면서 TV의 모든 픽셀이 영상을 보여줍니다.

돌아오려면 포인터를 화면 위쪽 가장자리로 옮기세요. 제목 표시줄이 내려오고 초록색 버튼으로 나갈 수 있습니다.

4단계: 소리 제대로 나오게 하기

HDMI로 연결하면 오디오가 영상과 같은 케이블로 전달되므로 TV 스피커로 재생되며 따로 설정할 것이 없습니다. AirPlay로는 소리가 AirPlay 대상 기기를 따라갑니다. 블루투스 스피커나 헤드폰으로 듣고 싶다면 평소처럼 iOS에서 연결하세요. XeOS는 iOS가 라우팅하는 대로 소리를 재생합니다.

탭 한 번으로 끝나는 경험 만들기

이것이 습관이 된다면 YouTube를 자체 독 앱으로 설치하세요. YouTube를 연 다음 ⋯ › Add Site to Dock을 선택하세요. 독에 아이콘이 생기고 자체 창에서 열려 브라우저를 거칠 필요가 완전히 없어집니다.

탭을 독립된 플로팅 창으로 분리할 수도 있어, 한 창에서는 영상을 계속 재생하면서 다른 창에서 작업할 수 있습니다.

시청하는 동안 유용한 추가 기능

  • 확대/축소. Cmd +와 Cmd −는 사이트별로 페이지 확대/축소를 조정하며 설정이 기억됩니다. 소파에서 댓글을 읽을 때 유용합니다.
  • 읽기 모드. Cmd Shift R은 페이지를 텍스트만 남기고 단순화합니다. 영상에는 쓸모없지만, 다음에 연 기사에는 유용합니다.
  • 읽기 목록. ⋯ 메뉴에서 영상 페이지를 나중에 볼 수 있도록 저장하세요.
  • 다운로드. 툴바의 다운로드 버튼은 진행 상황과 속도가 표시된 다운로드 목록을 유지합니다.

자주 묻는 질문

광고 차단기가 YouTube 동영상 광고에도 작동하나요?

네. 차단 기능은 EasyList와 uBlock 필터 목록으로 브라우저 엔진에 컴파일되어 있으며, 건너뛸 수 있는 광고가 나타나면 자동으로 건너뜁니다.

다른 동영상 사이트에서도 작동하나요?

네. 웹사이트가 있는 것이라면 모두 같은 방식으로 재생됩니다. 초록색 버튼이 전체 화면으로 전환하고 화면이 패널을 가득 채웁니다.

매번 다시 로그인해야 하나요?

아니요. 세션은 재시작 후에도 유지됩니다. 쿠키와 사이트 저장소가 의도적으로 보존되어 로그인 상태가 유지됩니다.

재생 중에 휴대폰을 리모컨처럼 쓸 수 있나요?

네. 마우스가 연결되어 있지 않으면 휴대폰 화면이 트랙패드가 되어 TV를 건드리지 않고도 일시정지하거나 탐색할 수 있습니다.

TV에 여전히 검은 테두리가 보이는 이유는 무엇인가요?

이는 대개 앱이 아니라 TV 자체의 오버스캔이나 화면 크기 설정 때문입니다. TV의 화면 크기를 "Just Scan", "Screen Fit" 또는 "1:1"로 설정하고, 설정 › 디스플레이의 해상도가 TV가 보고하는 값과 일치하는지 확인하세요.
