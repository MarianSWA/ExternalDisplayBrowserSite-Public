没有 Stage Manager 的 iPad 外接显示器方案：让任意机型都能全屏使用

如果你的 iPad 没有搭载 M 系列芯片，Apple 在外接显示器上只给你一个选项：镜像。没有任何办法能实现「扩展桌面」而非「复制画面」，因此传到显示器上的，只是一份 iPad 屏幕的复制画面，保持着 iPad 自身的比例，出现在一块并非那个比例的面板上。这篇文章会说明这背后的原因，以及无论你的 iPad 内部搭载什么芯片，都能获得全屏桌面体验的方法。

Stage Manager 的现状，简要说明

Stage Manager 刚推出时，外接显示器支持是随之一起到来的，但后来被收回，只保留给 M1 及更新机型的 iPad。这条界线以下的机型都只能使用基础镜像功能。多年过去，情况依然如此：

iPad外接显示器表现
M 系列 iPad Pro / AirStage Manager：扩展桌面、真实窗口
A 系列 iPad Pro（2018、2020 等）仅支持镜像
iPad Air（M1 之前）、iPad、iPad mini仅支持镜像

一台 2020 年的 iPad Pro 是一台性能强劲的设备，它的 USB-C 接口足以驱动一块 4K 显示屏，只是不被允许在那块屏幕上显示任何与本机不同的内容。这是一条由软件划定的界线，而非硬件本身的限制，这也正是它让人感到恼火的地方。

为什么镜像在显示器上看起来不对劲

iPad 屏幕比例是 4:3，而显示器是 16:9。镜像模式会把一张 4:3 的画面交给显示器，显示器再用竖直黑边把它两侧夹住，有时黑边甚至占到整块面板的三分之一。这个方框内的所有内容，尺寸都是按「手臂长度握持平板」设计的，而不是按「隔着办公桌观看显示器」设计的。

这个问题无法在 iPadOS 中解决，因为 iPadOS 根本没有专门为显示器绘制任何内容，它只是在复制平板自身的屏幕画面。

解决方案：一款自行绘制桌面系统的应用

XeOS: External Display Browser 不采用镜像方式。它会接管外接显示器，并以显示器自身的分辨率渲染一整套桌面系统，因此一台 16:9 的显示器，得到的就是一块画面直达边缘的 16:9 桌面。iPad 本身 4:3 的屏幕比例，从此和显示屏上呈现的内容再无关系。

由于它是自行绘制整个环境的，因此完全不会向 iPadOS 请求 Stage Manager，也不在意你使用的是哪款芯片。任何支持视频输出的 iPad，都能获得完全相同的效果。

你能获得什么

  • 可以移动、调整大小、吸附到边缘并设为全屏的窗口，还能同时打开多个。
  • 一款桌面级浏览器，带标签页、书签栏、下载列表、已保存密码、阅读模式和内置广告拦截器。
  • 一款文件管理器，可挂载 iCloud 云盘文件夹、iPad 本机文件夹以及外接 USB 硬盘。
  • 一个支持批注的完整 PDF 查看器，外加 Office 文件预览功能。
  • 一款支持全屏幻灯片放映的照片应用。
  • 可安装在程序坞中的网站，各自拥有独立的图标和窗口。

完成设置

  1. 把 iPad 连接到显示器：USB-C 转 HDMI、USB-C 转 USB-C，或者如果还想同时获得供电和 USB 接口，可以使用多口转接器，AirPlay 同样可用。
  2. 打开 XeOS，它会检测到该显示屏并引导你完成设置。
  3. 选择显示器所报告的分辨率，并根据你的观看距离设置内容缩放比例。
  4. 配对蓝牙鼠标和键盘，或者把 iPad 屏幕当作触控板使用。

完整操作步骤请参阅设置指南。

iPad 专属注意事项

在 iPad 上，窗口总览的快捷键是 Option ↑，而不是 Ctrl ↑，因为 iPadOS 保留了 Ctrl 组合键的使用权。iPad 更大的屏幕，也让「屏幕充当触控板」这一备用方案变得足够舒适，如果你愿意，完全可以不必额外携带鼠标。而 Magic Keyboard 或任意蓝牙键盘也能正常使用：输入内容会进入外接显示器上当前获得焦点的输入框。

它不是什么

这是一套桌面环境，而不是「运行在显示器上的 iPadOS」。你 iPad 上的其他应用不会在其中运行，能运行的只有浏览器、内置应用，以及你安装的任意网站。对于大量日常工作而言，这已经足够胜任；但如果你特别需要在大屏幕上使用 Procreate 或 Final Cut，这款应用无法满足这个需求。

另外，部分网页内嵌元素，例如同意横幅，以及某些登录和支付框架，不会响应来自外接显示器的点击，因为 iOS 的浏览器引擎会对跨域框架进行加固，以抵御程序化输入。应用内置了一个一键点击即可解决的方案，详见设备布局模式指南。

常见问题

它能在 2018 款 iPad Pro 上使用吗？

可以。任何能向显示屏输出视频的机型都能使用。

需要开启 Stage Manager 吗？

不需要，它完全不使用 Stage Manager。

我能在 M 系列 iPad 上使用它吗？

可以。有些用户就算是在 M 系列 iPad 上，也更喜欢用它来获得全屏浏览器和内置广告拦截功能。

连接期间 iPad 能充电吗？

只有当连接线本身支持供电时才可以，也就是需要一个带透传充电功能的多口转接器，或一台能够供电的 USB-C 显示器。
