黒帯とはもうお別れ。真のマルチタスク・デスクトップ体験を。

XeOSは、外部画面の隅から隅まで、iPhone/iPadにデスクトップOSさながらの体験をもたらします。

YouTubeや動画をフルスクリーンで

YouTubeや動画をフルスクリーンで

  • YouTubeが黒帯なしで画面全体に表示
  • Twitch、Vimeoなど、あらゆるストリーミングサイトに対応
  • ページ内動画も、フルスクリーン切り替えも両方対応

大きな外部モニターやポータブルディスプレイでの黒帯は本当に煩わしいものです。XeOS: External Display Browserなら、YouTube、Twitch、Vimeo、どんな動画も画面端から端まで埋め尽くします。

本物のウィンドウ、本物のマルチタスク

本物のウィンドウ、本物のマルチタスク

  • 本物のウィンドウをドラッグ、リサイズ、重ね合わせ
  • ウィンドウ切り替えと全ウィンドウ一覧表示
  • どんなWebサイトも単体アプリとしてインストール可能

必要なだけウィンドウを開き、デスクトップと同じ感覚で配置できます。ドラッグ、リサイズ、重ね合わせ、フルスクリーン、さらに開いているものすべてを見渡せるミッションコントロール風の一覧表示も。

iPhoneでデスクトップクラスの体験を得る、最も簡単な方法

iPhoneを外部モニター、ポータブルモニター、テレビ、プロジェクターに接続するだけで、ファイルシステム、アプリ、フルスクリーンブラウジングを備えた本格的なデスクトップ体験がすぐに手に入ります。

ステップ1

外部・ポータブルディスプレイに接続

USB-C to HDMIまたはUSB-C to USB-Cアダプターを使って、iPhoneやiPadを外部モニター、ポータブルモニター、テレビ、プロジェクターに接続します。XeOS: External Display Browserが接続を自動検出し、画面の隅々まで表示を埋め尽くします。

ステップ2

Bluetoothマウス&キーボードを追加(任意)

Bluetoothマウスとキーボードをペアリングすれば、外部ディスプレイでフルブラウザ体験が可能に。iPhone向けとして最高のSamsung DeX代替アプリです。オンスクリーン操作でも快適に使えます。

ステップ3

デスクトップクラスの体験を楽しむ

ファイル管理、PDFへの注釈、Officeドキュメントのプレビュー、メディア再生、フルスクリーンでのWeb閲覧まで。お気に入りのサイトを単体アプリとしてインストールでき、黒帯は二度と表示されません。

デスクトップクラスのアプリに必要なすべて

iPhoneの外部ディスプレイ専用に設計された、ネイティブアプリとツール一式。

サイトをアプリとしてインストール&マルチタスク

お気に入りのWebサイトを単体アプリとしてインストール。複数のウィンドウを浮かせて、ドラッグ&リサイズしながら必要なものを常に表示しておけます。

YouTube、Netflix、Twitch、その他あらゆるオンライン動画を、外部モニターで完全なフルスクリーン表示。サイドバーも黒帯もなく、画面全体を埋め尽くす純粋なフルスクリーン動画です。

メディアプレイヤー&生産性アプリ

写真・動画・音声用の内蔵プレイヤーを搭載。メモや電卓アプリも統合されているので、作業もはかどります。

ファイルシステム&ドキュメントプレビュー

ダウンロードを管理できる本格的なファイルシステム。PDFを開いて注釈を付けたり、Word・Excel・PowerPointの文書を大画面で直接プレビューできます。

iPhoneやiPadをモニター、テレビ、プロジェクターに接続して画面を埋め尽くす方法

iPhoneをテレビにつなぐこと自体は簡単です。難しいのは、そこから使えるだけの画面を引き出すことです。標準のiOSはただ画面をミラーリングするだけなので、16:9のモニターには縦長のスマホ型の映像が、2本の黒帯に挟まれて浮かんで表示されます。XeOSは、そのミラーリングを、パネルのすべてのピクセルを使い切るデスクトップに置き換えます。このページの設定を一度済ませておけば、以降のすべてのガイドはそれが済んでいる前提で進みます。

iPhoneでデスクトップ体験を得るために知っておきたいこと

External Display Browserについて

iPhone・iPad向け最高のSamsung DeX代替アプリ。本当に使えるデスクトップ体験を実現します!

XeOS: External Display Browserが黒帯をなくす仕組み

iPhoneを外部モニターやポータブルディスプレイに接続すると、標準アプリはiPhoneの縦長画面向けに設計されているため、余った領域を黒帯で埋めてしまいます。XeOS: External Display Browserは、接続先ディスプレイの横長解像度をフルに使ってブラウザUIを描画するため、上下左右どこにも黒帯が出ません。外部モニター、ポータブルディスプレイ、テレビ、プロジェクターのすべてのピクセルが活用されます。

  • •YouTube、Netflix、Twitchなどあらゆるオンライン動画プラットフォームを外部ディスプレイで真のフルスクリーン再生
  • •Zoom、Google Meet、Microsoft Teamsなどのウェブ会議に、カメラ・マイクをフル対応
  • •ブラウザからあらゆるファイルをダウンロードし、PDF、Word/Excel/PowerPoint文書、画像/動画/音声を開く
  • •iPhone外部ディスプレイブラウザをデスクトップ並みに操作できる、Bluetoothマウス&キーボードのフル対応
  • •自動解像度検出により、あらゆるHDMIモニター、テレビ、プロジェクターの解像度に対応
  • •映像出力に対応するすべてのiPhoneモデルで動作。Lightning-HDMI、USB-C-HDMI、USB-C-USB-Cアダプター経由
  • •iPhoneのXeOS: External Display Browserは隅から隅まで表示、ピラーボックスやレターボックス、黒帯は一切なし
