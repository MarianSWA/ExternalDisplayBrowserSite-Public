Stage Manager非対応でも、iPadを外部ディスプレイでフルスクリーンに:あらゆるモデルで

お使いのiPadにM系チップが搭載されていない場合、外部モニターに関してAppleが用意している選択肢はミラーリングただ一つです。デスクトップを拡張する手段はなく複製されるだけなので、モニターに届くのはiPadの画面のコピーであり、iPadの縦横比のまま、それとは違う縦横比のパネルに表示されます。ここでは、なぜそうなるのか、そして中身のチップに関係なく、どのiPadでもフルスクリーンのデスクトップを実現する方法を解説します。

Stage Managerの現状、簡単に

Stage Managerの登場時には外部ディスプレイ対応も一緒に発表されましたが、その後M1以降のiPadのみに絞られました。それより前の世代はすべて、基本的なミラーリングのままです。それから何年も経った今も、状況は変わっていません。

2020年モデルのiPad Proは、4Kディスプレイを駆動できるUSB-Cポートを備えた高速なマシンです。ただ、そのディスプレイに違う内容を映すことが許されていないだけです。これはハードウェアの制約ではなくソフトウェアの制約であり、だからこそもどかしいのです。

モニターでミラーリングがおかしく見える理由

iPadは4:3、モニターは16:9です。ミラーリングはモニターに4:3の映像を渡し、モニター側は両側を黒でピラーボックス化します。パネルの3分の1が黒に埋まることもあります。その枠の中身はすべて、デスク越しの画面ではなく、腕を伸ばして持つタブレット向けのサイズで描かれています。

iPadOS側では直せません。そもそもiPadOSはモニター向けに何も描画しておらず、タブレット自身の画面をそのまま複製しているだけだからです。

解決策:独自にデスクトップを描画するアプリ

XeOS: External Display Browserはミラーリングを行いません。外部ディスプレイの制御を引き継ぎ、モニター本来の解像度でデスクトップを描画するため、16:9のモニターには端から端まで16:9のデスクトップが表示されます。iPad自体の4:3という縦横比は、そこに表示される内容とは無関係になります。

独自の環境を描画するため、iPadOSにStage Managerを要求することは一切なく、どのチップを搭載しているかも問いません。映像出力に対応するどのiPadでも、同じ結果が得られます。

できること

  • 移動、サイズ変更、端へのスナップ、フルスクリーン化ができるウィンドウを、複数同時に。
  • タブ、ブックマークバー、ダウンロード、保存済みパスワード、リーダーモード、内蔵広告ブロッカーを備えたデスクトップ用ブラウザ。
  • iCloud Driveのフォルダ、iPad本体のフォルダ、外部USBドライブをマウントできるファイルマネージャー。
  • 注釈対応の本格的なPDFビューア、加えてOfficeファイルのプレビュー。
  • フルスクリーンスライドショー対応の写真アプリ。
  • それぞれ専用のアイコンとウィンドウを持つ、Dockにインストール可能なWebサイト。

セットアップする

  1. iPadをディスプレイに接続します。USB-C to HDMI、USB-C to USB-C、給電とUSBポートも欲しい場合はマルチポートアダプター。AirPlayでも動作します。
  2. XeOSを開きます。ディスプレイを検出し、セットアップを進めます。
  3. モニターが報告する解像度を選び、視聴距離に合わせてコンテンツスケールを設定します。
  4. Bluetoothマウスとキーボードをペアリングするか、iPadの画面をトラックパッドとして使います。

詳しい手順はセットアップガイドにあります。

iPad特有の注意点

ウィンドウの一覧表示は、iPadではCtrl ↑ではなくOption ↑です。iPadOSがCtrlの組み合わせを予約しているためです。iPadの大きな画面のおかげで、画面をトラックパッドとして使うフォールバック機能も十分快適なので、マウスを持ち歩かずに済ませることもできます。Magic Keyboardや任意のBluetoothキーボードも通常通り使え、入力内容は外部ディスプレイ上でフォーカスされているフィールドに送られます。

これは何ではないか

これはモニター上のiPadOSではなく、デスクトップ環境です。他のiPadアプリがこの中で動作するわけではありません。動作するのはブラウザ、内蔵アプリ、インストールしたWebサイトです。多くの作業にとってはそれで十分ですが、大画面でProcreateやFinal Cutをどうしても使いたい場合、これはその答えにはなりません。

また、一部の埋め込みページ要素、同意バナー、特定のサインインや決済フレームは、外部ディスプレイからのクリックを受け付けません。iOSのブラウザエンジンが、クロスドメインのフレームをプログラムによる入力に対して強化しているためです。これにはワンタップの回避策が組み込まれており、デバイスレイアウトモードのガイドで説明しています。

XeOS: External Display Browserは、Stage ManagerもM系チップも不要で、どのiPadでもどんなモニターでもフルスクリーンのデスクトップを実現します。

よくある質問

2018年モデルのiPad Proでも使えますか?

はい。ディスプレイに映像出力できる機種であれば動作します。

Stage Managerをオンにしておく必要はありますか?

いいえ、Stage Managerは一切使用しません。

M系チップ搭載のiPadでも使えますか?

はい。フルスクリーンブラウザや内蔵広告ブロッカーを目的に、そちらでも好んで使う人がいます。

接続中、iPadは充電されますか?

接続が給電に対応している場合のみです。パススルー充電対応のマルチポートアダプターか、給電機能のあるUSB-Cモニターが必要です。
